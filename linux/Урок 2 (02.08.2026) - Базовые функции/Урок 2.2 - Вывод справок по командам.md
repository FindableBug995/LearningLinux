## 3. Получение справочной информации

### 3.1. `whatis` — краткая справка в одну строку

```bash
whatis clear
whatis history
whatis reset
```

Выводит краткое описание команды (одну строку).

### 3.2. `help` — справка для встроенных команд оболочки

```bash
help cd
help history
```

Используется для встроенных команд bash (built-ins). Для внешних команд этот способ не работает.

### 3.3. `--help` — справка для большинства команд

```bash
history --help
ls --help
```

Универсальный способ получить краткую справку по команде. Работает для большинства внешних утилит.

### 3.4. `man` — полное руководство пользователя

```bash
man clear
man history
```

- `man` — от manual (руководство)
    
- Открывает подробную документацию с описанием всех опций
    
- **Навигация:** `Page Up` / `Page Down`, стрелки, колесо мыши
    
- **Выход:** нажать `q` (quit)
    

### 3.5. `info` — альтернативная документация

```css
info clear
```

Более подробная документация в другом формате (иногда содержит больше информации, чем man).

### 3.6. Регистр букв в Linux

Все команды вводятся в **нижнем регистре**. Пример:

- `man` — работает
    
- `MAN` — `command not found`

## 4. Поиск команд

### 4.1. Двойной `Tab` — автодополнение с подсказкой

Набрать начало команды и нажать `Tab` дважды:

```php-template
hi<Tab><Tab>
```

Терминал покажет все команды, начинающиеся с `hi` (например, `history`, `hit` и др.).

### 4.2. `apropos` — поиск команд по описанию

```nginx
apropos his
```

Ищет команды, в названии или описании которых встречается указанная строка. Полезно, когда забыли точное название команды, но помните её назначение.

## 5. История команд

Команда `history` отображает список ранее выполненных команд.

### 5.1. Просмотр истории

```bash
history          # показать всю историю
history 10       # показать последние 10 команд
history 5        # показать последние 5 команд
```

### 5.2. Запуск команд из истории

Каждая команда в выводе `history` имеет номер. Используйте `!` для повторного выполнения:

|Синтаксис|Действие|
|---|---|
|`!37`|Выполнить команду с номером 37|
|`!!`|Выполнить предыдущую команду|
|`!-6`|Выполнить шестую команду с конца списка|

### 5.3. Поиск по истории

**Горячая клавиша:** `Ctrl + R`

- Начать вводить фрагмент команды
    
- Терминал показывает последнее совпадение
    
- `Ctrl + R` повторно — переход к более ранним совпадениям
    
- `Enter` — выполнить найденную команду
    
- `Tab` — выбрать команду для редактирования
    

### 5.4. Управление историей

|Команда|Действие|
|---|---|
|`history -c`|Очистить историю команд|
|`<пробел> команда`|Команда с пробелом в начале **не** попадает в историю|

_Пример скрытия команды из истории:_

```bash
 ls          # обычная команда — попадёт в историю
 cd /        # команда с пробелом — не попадёт в историю
```
