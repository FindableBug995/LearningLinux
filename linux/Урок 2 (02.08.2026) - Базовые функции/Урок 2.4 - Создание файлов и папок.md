## 1. Создание папок — `mkdir`

Команда `mkdir` (Make Directory) используется для создания новых директорий.

### 1.1. Базовое использование

```bash
mkdir LinuxCourse
```

Создаёт папку `LinuxCourse` в текущей директории.

### 1.2. Создание нескольких папок за раз

```bash
mkdir folder1 folder2 folder3
```

Создаёт три папки одновременно.

### 1.3. Создание вложенной структуры — ключ `-p`

```bash
mkdir -p parent/child/grandchild
```

Ключ `-p` (parents) позволяет создавать цепочки вложенных папок одной командой. Если промежуточные папки отсутствуют, они будут созданы автоматически.

_Пример:_ после выполнения `mkdir -p 2/3/4` будет создана структура:

2/
└── 3/
    └── 4/

### 1.4. Особенности имён в Linux

**Регистрозависимость:**

- `folder1` и `Folder1` — это **разные** папки
    
- В отличие от Windows, где имена, отличающиеся только регистром, считаются одинаковыми
    

**Специальные обозначения в выводе `ls -l` / `ll`:**

- `.` (одна точка) — ссылка на текущую папку
    
- `..` (две точки) — ссылка на родительскую папку
    

### 1.5. Ошибка доступа и `sudo`

Если при создании папки возникает ошибка:

> mkdir: cannot create directory 'name': Permission denied

Необходимо проверить местоположение. Если папка действительно должна создаваться в указанном месте, используйте `sudo` для получения прав суперпользователя:

```bash
sudo mkdir /protected_folder
```

_Важно:_ при использовании `sudo` папка создаётся с правами root. Если путь начинается с `/` (корень), папка будет создана в корне файловой системы, а не в текущей директории.

## Просмотр структуры папок — `tree`

Утилита `tree` отображает структуру директорий в наглядном древовидном виде.

### 2.1. Установка

```bash
sudo apt install tree
```

### 2.2. Использование

```bash
tree                # показать структуру текущей папки
tree /home          # показать структуру указанной папки
```

## 3. Создание файлов

В Linux существует несколько способов создания файлов.

### 3.1. `touch` — создание пустого файла или обновление даты

```bash
touch file.txt
```

- Если файл не существует — создаётся пустой файл
    
- Если файл существует — обновляется только временная метка (модификация), содержимое не изменяется
    

### 3.2. Перенаправление вывода (`>`)

**С помощью `echo`:**

```bash
echo "some text" > file1.txt
```

Создаёт файл с указанным содержимым (или перезаписывает существующий).

**Без `echo` (только перенаправление):**

```markdown
> file2.txt
```

Создаёт пустой файл (аналог `touch`).

### 3.3. `cat` — создание файла с многострочным содержимым

```bash
cat > file3.txt
```

После выполнения команды терминал переходит в режим ввода:

- Вводите строки текста, нажимая `Enter` после каждой
    
- Для завершения ввода нажмите **`Ctrl + D`**
    

_Проверка результата:_

```bash
cat file3.txt       # выведет содержимое файла
```

## 4. Расширения файлов в Linux

В отличие от Windows, Linux **не использует расширения файлов для определения их типа**. Расширение (например, `.txt`, `.jpg`) является лишь частью имени и служит для удобства пользователя. Файлы могут:

- Не иметь расширения вообще
    
- Иметь любое расширение, не соответствующее фактическому содержимому
    

Система определяет тип файла по его содержимому (magic bytes), а не по расширению
