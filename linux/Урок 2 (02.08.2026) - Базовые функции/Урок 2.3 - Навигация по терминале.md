
В этом уроке рассмотрены базовые команды для навигации по файловой системе Linux:

|Команда|Назначение|
|---|---|
|`pwd`|Показать текущую директорию|
|`cd`|Сменить директорию (абсолютные и относительные пути, `..`, `~`, `-`)|
|`ls`|Просмотреть содержимое директории (ключи `-a`, `-l`, их комбинации)|
|`ll`|Псевдоним для `ls -al` (подробный список всех файлов)|

## 1. Определение текущей директории — `pwd`

Команда `pwd` (Print Working Directory) выводит полный путь к текущей директории, в которой находится пользователь.

```bash
pwd
```

_Пример вывода:_ `/home/itguy`

## 2. Смена директории — `cd`

Команда `cd` (Change Directory) используется для перемещения по файловой системе.

### 2.1. Основные варианты использования

|Команда|Действие|
|---|---|
|`cd /home`|Перейти в директорию `/home`|
|`cd itguy`|Перейти в поддиректорию `itguy` (относительно текущей позиции)|
|`cd ..`|Перейти в родительскую директорию (на уровень выше)|
|`cd ../..`|Перейти на два уровня выше|
|`cd /`|Перейти в корневую директорию|
|`cd ~` или `cd`|Перейти в домашнюю директорию текущего пользователя|
|`cd -`|Перейти в предыдущую директорию (с возвратом назад)|

### 2.2. Абсолютные и относительные пути

|Тип пути|Начало|Описание|Пример|
|---|---|---|---|
|**Абсолютный**|`/`|Полный путь от корня файловой системы. Не зависит от текущего местоположения.|`cd /var/log`|
|**Относительный**|любой символ, кроме `/`|Путь вычисляется относительно текущей директории.|`cd ../etc`|

### 2.3. Специальные обозначения в путях

|Обозначение|Значение|
|---|---|
|`.`|Текущая директория|
|`..`|Родительская директория|
|`~`|Домашняя директория текущего пользователя|

_Пример перемещения:_ `cd ../../var` — подняться на два уровня вверх, затем войти в директорию `var`.

## 3. Просмотр содержимого директорий — `ls`

Команда `ls` (LiSt) выводит список файлов и поддиректорий.

### 3.1. Основные ключи

|Ключ|Описание|
|---|---|
|`-a`|Показывает **все** файлы, включая скрытые (начинающиеся с точки)|
|`-l`|Выводит содержимое в виде таблицы (подробная информация: права доступа, владелец, размер, дата)|
|`-h`|Выводит размеры файлов в «человекочитаемом» формате (КБ, МБ) — обычно используется вместе с `-l`|

### 3.2. Примеры использования

```bash
ls              # список файлов в текущей директории
ls -a           # все файлы, включая скрытые
ls -l           # подробный (табличный) вывод
ls -la          # подробный вывод со скрытыми файлами
ls /var         # содержимое директории /var
ls -la /var     # подробный вывод со скрытыми файлами для /var
```

_Примечание:_ порядок ключей не имеет значения. `ls -al`, `ls -la`, `ls -a -l` дают одинаковый результат.

### 3.3. Скрытые файлы и директории

В Linux скрытые файлы и папки обозначаются начальной точкой в имени (например, `.bashrc`, `.config`). Команда `ls` без ключа `-a` их не показывает.

### 3.4. Псевдоним `ll`

Во многих дистрибутивах Linux (включая Ubuntu) команда `ll` является псевдонимом для `ls -al`. Она выводит подробный список всех файлов, включая скрытые.

```nginx
ll              # эквивалентно ls -al
```
