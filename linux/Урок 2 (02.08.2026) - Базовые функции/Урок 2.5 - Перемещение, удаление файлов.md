## 1. Копирование файлов и папок — `cp`

Команда `cp` (CoPy) используется для копирования файлов и директорий.

### 1.1. Копирование файлов

```bash
cp source_file destination_file
```

_Пример:_

```bash
cp newfile1.txt newfile1_copy.txt
```

### 1.2. Копирование с использованием шаблонов (wildcards)

Символ `*` (звёздочка) заменяет любую последовательность символов.

```bash
cp new* folder2/
```

Копирует все файлы, имена которых начинаются с `new`, в папку `folder2`.

### 1.3. Копирование папок — ключ `-r`

Для копирования директорий необходимо использовать ключ `-r` (recursive):

```bash
cp -r source_folder destination_folder
```

_Пример:_

```bash
cp -r folder2 folder2_copy
```

## 2. Перемещение и переименование — `mv`

Команда `mv` (MoVe) используется для перемещения файлов и папок, а также для их переименования.

### 2.1. Перемещение файлов

```bash
mv file.txt destination_folder/
```

_Пример: переместить все `.txt` файлы в папку `folder1`:_

```nginx
mv *.txt folder1/
```

### 2.2. Перемещение папок

```bash
mv source_folder destination_folder/
```

### 2.3. Переименование (частный случай перемещения)

В Linux нет отдельной команды для переименования. Переименование выполняется командой `mv`:

```bash
mv old_name.txt new_name.txt
```

## 3. Удаление файлов и папок — `rm`

Команда `rm` (ReMove) удаляет файлы и директории.

### 3.1. Удаление файлов

```bash
rm file.txt
```

### 3.2. Удаление папок — ключ `-r`

Для удаления директории с содержимым требуется ключ `-r` (recursive):

```bash
rm -r folder_name
```

### 3.3. Принудительное удаление — ключ `-f`

Ключ `-f` (force) подавляет запросы подтверждения и игнорирует несуществующие файлы:

```bash
rm -rf folder_name
```

### 3.4. Комбинирование ключей

Ключи можно объединять:

```bash
rm -rf folder_name          # рекурсивное принудительное удаление
rm -r -f folder_name        # то же самое
```

## 4. Важные предостережения

### 4.1. Удаление не попадает в корзину

Файлы, удалённые командой `rm`, **не перемещаются в корзину** и **не могут быть восстановлены** стандартными средствами. Удаление происходит безвозвратно.


### 4.2. Отсутствие предупреждений

По умолчанию `rm` не выводит запросов на подтверждение. Ключ `-i` (interactive) включает режим с подтверждением:

```bash
rm -i important_file.txt
```

### 4.3. Опасная команда

```bash
rm -rf /
```

Эта команда пытается рекурсивно принудительно удалить всё из корня файловой системы (`/`). В большинстве современных систем она заблокирована (требуется дополнительный ключ `--no-preserve-root`), но принцип остаётся: **будьте предельно осторожны с `rm`**.

**Важные особенности:**

- В **Linux** переименование выполняется командой **`mv`**
    
- Шаблон **`*`** (звёздочка) используется для групповых операций с файлами
    
- Удаление через **`rm`** происходит безвозвратно, без перемещения в корзину
    
- Регистр букв в именах имеет значение (`folder1` ≠ `Folder1`)
    
- Будьте осторожны с командой **`rm -rf`** — это мощный инструмент, который при неосторожном использовании может привести к потере данных
