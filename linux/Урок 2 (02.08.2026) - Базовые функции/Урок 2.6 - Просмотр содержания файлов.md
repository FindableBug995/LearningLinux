## Просмотр файлов с помощью `more`

Команда `more` — старейшая утилита для постраничного просмотра текстовых файлов.

### 2.1. Базовое использование

```dos
more filename.txt
```

- **Пробел** — следующая страница
    
- **Q** — выход
    

### 2.2. Полезные опции

|Опция|Действие|
|---|---|
|`-<число>`|Показывать указанное количество строк за раз|
|`+<число>`|Начать вывод с определённой строки|
|`+/<строка>`|Начать вывод со строки, содержащей указанный текст|
|`-s`|«Схлопывает» повторяющиеся пустые строки в одну|

### 2.3. Примеры использования

```1c
more -10 filename.txt              # по 10 строк на страницу
more +145 filename.txt             # начать со 145-й строки
more +145 -5 filename.txt          # начать со 145-й строки, показывать по 5 строк
more +/Romeo filename.txt          # начать со строки, содержащей Romeo
more -s filename.txt               # схлопнуть пустые строки
```

**Важно:** поиск в `more` чувствителен к регистру. Строка `+/romeo` не найдёт `Romeo`.


## 3. Просмотр файлов с помощью `less`

Команда `less` — более современная и функциональная альтернатива `more`. Название является игрой слов («less is more»).

### 3.1. Базовое использование

```cmake
less filename.txt
```

### 3.2. Навигация в `less`

|Клавиша|Действие|
|---|---|
|`Пробел`|Страница вниз|
|`Page Down`|Страница вниз|
|`Page Up`|Страница вверх|
|`Стрелка вверх/вниз`|Построчная навигация|
|`Стрелка влево/вправо`|Горизонтальная прокрутка|
|`Q`|Выход|

### 3.3. Поиск в `less`

**Чувствительный к регистру:**

```cmake
less -p"Romeo" filename.txt
```

**Нечувствительный к регистру (ключ `-i`):**

```css
less -i -p"romeo" filename.txt
```

Или комбинированно:

```cmake
less -ip"romeo" filename.txt
```

### 3.4. Нумерация строк

```cmake
less -N filename.txt
```

Ключ `-N` (заглавная) выводит номера строк.

### 3.5. Комбинирование опций

Опции можно объединять:

```css
less -N -i -p"romeo" filename.txt
```


## 4. Просмотр начала файла — `head`

Команда `head` выводит первые строки файла.

### 4.1. Базовое использование

```bash
head filename.txt          # по умолчанию 10 строк
```

### 4.2. Управление количеством строк

```bash
head -n 5 filename.txt     # первые 5 строк
head -5 filename.txt       # то же самое (сокращённая запись)
```

### 4.3. Вывод в байтах

```bash
head -c 47 filename.txt    # первые 47 байт
```

## 5. Просмотр конца файла — `tail`

Команда `tail` выводит последние строки файла.

### 5.1. Базовое использование

```bash
tail filename.txt          # по умолчанию последние 10 строк
```

### 5.2. Управление количеством строк

```bash
tail -n 3 filename.txt     # последние 3 строки
tail -3 filename.txt       # то же самое
```

### 5.3. Вывод в байтах

```bash
tail -c 100 filename.txt   # последние 100 байт
```

## Итог

В этом уроке рассмотрены основные утилиты для просмотра текстовых файлов в терминале Linux:

| Команда | Назначение                            | Ключи                                                            |
| ------- | ------------------------------------- | ---------------------------------------------------------------- |
| `more`  | Постраничный просмотр (вперёд)        | `-<число>`, `+<число>`, `+/<строка>`, `-s`                       |
| `less`  | Постраничный просмотр (в обе стороны) | `-N` (нумерация), `-p` (поиск), `-i` (регистронезависимый поиск) |
| `head`  | Просмотр начала файла                 | `-n` (строки), `-c` (байты)                                      |
| `tail`  | Просмотр конца файла                  | `-n` (строки), `-c` (байты)                                      |

**Важные особенности:**

- Поиск в `more` и `less` по умолчанию чувствителен к регистру
    
- `less` позволяет перемещаться как вперёд, так и назад по файлу
    
- `head` и `tail` удобны для быстрого ознакомления с содержимым без открытия полноценного просмотрщика
    
- Все утилиты корректно работают с текстовыми файлами любого размера, не загружая их целиком в память
