
В этом уроке рассмотрены команды для смены владельца и группы-владельца файлов и директорий:

|Команда|Назначение|Ключи|
|---|---|---|
|`sudo chown username file`|Сменить владельца|`-R` (рекурсивно)|
|`sudo chown :groupname file`|Сменить группу|`-R`|
|`sudo chown username:groupname file`|Сменить владельца и группу|`-R`|
|`sudo chgrp groupname file`|Сменить только группу|`-R`|

**Ключевые понятия:**

- Обе команды требуют прав root (`sudo`)
    
- Ключ `-R` (recursive) применяет изменения ко всем вложенным файлам и папкам
    
- При смене владельца текущей директории можно потерять доступ к ней (но root всегда имеет доступ)
    
- `chown` универсальнее, `chgrp` специализируется только на группах

## 1. Смена владельца и группы — `chown`

Команда `chown` (change owner) используется для изменения владельца и/или группы-владельца файлов и директорий. Это **административная команда**, требующая прав root (выполняется с `sudo`).

### 1.1. Базовый синтаксис

```css
sudo chown [опции] [владелец][:группа] файл
```

### 1.2. Варианты использования

|Синтаксис|Действие|
|---|---|
|`chown username file`|Изменить только владельца|
|`chown :groupname file`|Изменить только группу-владельца|
|`chown username:groupname file`|Изменить одновременно владельца и группу|
|`chown username: file`|Изменить владельца, группа устанавливается как основная группа пользователя|

### 1.3. Примеры

**Смена только владельца:**

```bash
sudo chown outgoinghr anotherfile
```

После выполнения владельцем файла `anotherfile` станет пользователь `outgoinghr`.

**Смена только группы:**

```bash
sudo chown :remoteworkers important.txt
```

Группа-владелец файла `important.txt` меняется на `remoteworkers`.

**Смена владельца и группы одновременно:**

```bash
sudo chown salesguy:remoteworkers onemorefile
```

Владелец — `salesguy`, группа-владелец — `remoteworkers`.

**Смена группы у всех файлов в текущей папке:**

```bash
sudo chown :itguy *
```

Символ `*` (звёздочка) обозначает все файлы в текущей директории.

## 2. Рекурсивная смена владельца — `-R`

Ключ `-R` (recursive) применяет изменения ко всем файлам и поддиректориям внутри указанной директории.

### 2.1. Синтаксис

```bash
sudo chown -R username:groupname directory/
```

### 2.2. Пример

```bash
sudo chown -R outgoinghr:remoteworkers ./
```

Меняет владельца и группу для текущей директории (`.`) и **всех** вложенных в неё файлов и папок.

### 2.3. Важное предостережение

Если изменить владельца текущей директории на другого пользователя, можно потерять возможность просматривать её содержимое без `sudo`. Однако root всегда имеет доступ к любым файлам независимо от прав.

_Пример проблемы:_

```bash
sudo chown outgoinghr:remoteworkers .     # владелец текущей папки изменён
ls .                                      # ошибка: Permission denied
sudo ls .                                 # работает (с правами root)
```

Для восстановления доступа можно вернуть права владельцу или выставить права `777`:

```bash
sudo chmod 777 .                         # временное решение
sudo chown itguy:itguy .                 # вернуть владельца
```

## 3. Смена только группы — `chgrp`

Команда `chgrp` (change group) предназначена исключительно для смены группы-владельца. Это также административная команда.

### 3.1. Базовый синтаксис

```bash
sudo chgrp [опции] groupname file
```

### 3.2. Примеры

**Смена группы для одного файла:**

```bash
sudo chgrp remoteworkers somedoc.txt
```

**Смена группы для текущей директории:**

```bash
sudo chgrp officeworkers .
```

**Рекурсивная смена группы для директории и всех вложенных объектов:**

```bash
sudo chgrp -R officeworkers ./
```

## 4. Сравнение `chown` и `chgrp`

|Команда|Назначение|Особенности|
|---|---|---|
|`chown`|Смена владельца и/или группы|Может менять и то, и другое одной командой|
|`chgrp`|Смена только группы|Специализированная команда, не меняет владельца|

Обе команды требуют прав root (выполняются через **`sudo`**).

## 5. Практические примеры

### 5.1. Подготовка тестовой среды

```1c
# Создать группу (если не существует)
sudo groupadd remoteworkers
```

> # remoteworkers:x:1006:itguy,outgoinghr

### 5.2. Смена владельца файла

```bash
sudo chown outgoinghr important.txt
ls -l important.txt
```

> # -rw-r--r-- 1 outgoinghr itguy 0 Mar 26 10:00 important.txt

### 5.3. Смена группы файла

```bash
sudo chown :remoteworkers important.txt
ls -l important.txt
```

> # -rw-r--r-- 1 outgoinghr remoteworkers 0 Mar 26 10:00 important.txt

### 5.4. Смена владельца и группы одновременно

```bash
sudo chown salesguy:remoteworkers onemorefile
```

### 5.5. Смена группы у всех файлов в папке

```bash
sudo chgrp itguy *
```

### 5.6. Рекурсивная смена группы для директории

```bash
sudo chgrp -R officeworkers ./
ls -l    # все файлы внутри получат группу officeworkers
```
