- **Дополнительные группы** — назначаются отдельно
    
- **Принцип минимальных прав** — работа с минимально необходимыми привилегиями

## 1. Информация о текущем пользователе

### 1.1. `whoami` — имя текущего пользователя

```bash
whoami
```

Выводит логин пользователя, от имени которого выполняется текущая сессия.

### 1.2. `groups` — группы пользователя

```bash
groups
```

Выводит список групп, в которые входит текущий пользователь.

### 1.3. `id` — подробная информация о пользователе

```bash
id
```

Выводит:

- **uid** (User ID) — числовой идентификатор пользователя
    
- **gid** (Group ID) — числовой идентификатор основной группы
    
- **groups** — список дополнительных групп с их идентификаторами
    

_Пример вывода:_

> uid=1000(itguy) gid=1000(itguy) groups=1000(itguy),4(adm),27(sudo)

## 2. Переключение между пользователями

### 2.1. `su` — Switch User

```nginx
su username
```

Переключает текущую сессию на указанного пользователя. Требуется ввод пароля целевого пользователя.

_Пример:_

```nginx
su salesguy
```

### 2.2. `sudo su` — переключение на root

```bash
sudo su
```

Переключает на пользователя **root** (суперпользователя). Требует ввода пароля текущего пользователя (если он есть в группе sudo).

### 2.3. `exit` — возврат к предыдущему пользователю

```bash
exit
```

Завершает текущую сессию и возвращает к предыдущему пользователю.

### 2.4. Признаки в командной строке

| Символ в конце приглашения | Значение                 |
| -------------------------- | ------------------------ |
| `$`                        | Обычный пользователь     |
| `#`                        | Суперпользователь (root) |
## 3. Root и принцип минимальных прав

### 3.1. `sudo` — выполнение команды с правами root

```bash
sudo apt install zip
```

Префикс `sudo` позволяет выполнить команду от имени суперпользователя без полного переключения на root.

### 3.2. Почему не стоит работать от root постоянно

- **Безопасность** — случайное выполнение опасной команды может привести к повреждению системы
    
- **Принцип минимальных прав** — в Linux принято выдавать пользователю ровно те права, которые необходимы для выполнения текущих задач
    
- **Аудит** — при работе через `sudo` действия логируются, что позволяет отследить, кто и что делал
    

_Пример:_ если разработчику нужно только читать логи и править конфигурации, администратор выдаст доступ к конкретным файлам, а не права root.

## 4. UID и GID — идентификаторы пользователей и групп

При создании нового пользователя в Linux:

1. Назначается уникальный **UID** (User ID) — числовой идентификатор
    
2. Автоматически создаётся одноимённая группа с **GID** (Group ID)
    
3. Эта группа становится **основной (primary)** для пользователя
    
4. Пользователь может быть добавлен в **дополнительные (secondary)** группы
    

|Понятие|Описание|
|---|---|
|**UID**|User ID — уникальный числовой идентификатор пользователя|
|**GID**|Group ID — идентификатор основной группы|
|**Основная группа**|Группа, присвоенная пользователю по умолчанию (создаётся автоматически)|
|**Дополнительные группы**|Группы, в которые пользователь включён помимо основной|
## 5. Информация об активных пользователях

### 5.1. `users` — список логинов

```bash
users
```

Выводит список имён пользователей, которые в данный момент работают в системе (включая удалённые сессии).

### 5.2. `who` — информация о сессиях

```bash
who
```

Выводит таблицу с информацией:

- Логин пользователя
    
- Тип терминала (tty — локально, pts — удалённо)
    
- Время входа
    
- IP-адрес (для удалённых подключений)
    

### 5.3. `w` — расширенная информация

```undefined
w
```

Выводит:

- Текущее время, время работы системы, количество пользователей
    
- Для каждого пользователя: логин, терминал, время входа, нагрузку, текущую команду
    

_Пример вывода `w`:_

>  14:30:15 up 2 days,  3:45,  2 users,  load average: 0.08, 0.03, 0.01
> USER     TTY      FROM             LOGIN@   IDLE   JCPU   PCPU WHAT
> itguy    tty7     :0               10:15    4:12m  2:15   0.20s /usr/bin/gnome-shell
> salesguy pts/0    192.168.1.100    14:20    0.00s  0.05s  0.01s sshd: salesguy
