# Горячие клавиши в редакторе Nano

**Работа с файлами**

|Сочетание клавиш|Действие|
|---|---|
|**Ctrl + S**|Сохранить текущий файл|
|**Ctrl + O**|Предложить записать файл под другим именем (Сохранить как)|
|**Ctrl + R**|Вставить содержимое другого файла в текущий|
|**Ctrl + X**|Закрыть буфер / Выйти из nano|

### **Редактирование текста**

|Сочетание клавиш|Действие|
|---|---|
|**Ctrl + K**|Вырезать текущую строку в буфер обмена|
|**Alt + 6**|Копировать текущую строку в буфер обмена|
|**Ctrl + U**|Вставить содержимое буфера обмена|
|**Alt + T**|Вырезать текст от курсора до конца файла|
|**Ctrl + ]**|Дописать текущее слово|
|**Alt + 3**|Закомментировать/раскомментировать строку или выделенную область|
|**Alt + U**|Отменить последнее действие|
|**Alt + E**|Повторить последнее отменённое действие|

### **Поиск и замена**

|Сочетание клавиш|Действие|
|---|---|
|**Ctrl + Q**|Начать поиск назад (вверх по тексту)|
|**Ctrl + W**|Начать поиск вперёд (вниз по тексту)|
|**Alt + Q**|Найти следующее совпадение (при поиске назад)|
|**Alt + W**|Найти следующее совпадение (при поиске вперёд)|
|**Alt + R**|Начать сеанс поиска и замены|

### **Удаление текста**

|Сочетание клавиш|Действие|
|---|---|
|**Ctrl + H**|Удалить символ перед курсором|
|**Ctrl + D**|Удалить символ под курсором|
|**Alt + Backspace**|Удалить слово слева от курсора|
|**Ctrl + Delete**|Удалить слово справа от курсора|
|**Alt + Delete**|Удалить текущую строку|

### **Операции с текстом**

|Сочетание клавиш|Действие|
|---|---|
|**Ctrl + T**|Выполнить внешнюю команду|
|**Ctrl + J**|Выровнять абзац или выделенную область|
|**Alt + J**|Выровнять весь буфер|
|**Alt + B**|Запустить проверку синтаксиса|
|**Alt + F**|Запустить форматирование/исправление кода|
|**Alt + :**|Начать/остановить запись макроса|
|**Alt + ;**|Воспроизвести записанный макрос|

### **Навигация по тексту**

|Сочетание клавиш|Действие|
|---|---|
|**Ctrl + B**|На один символ назад|
|**Ctrl + F**|На один символ вперёд|
|**Ctrl + ←**|На одно слово назад|
|**Ctrl + →**|На одно слово вперёд|
|**Ctrl + A**|В начало строки|
|**Ctrl + E**|В конец строки|
|**Ctrl + P**|На строку вверх|
|**Ctrl + N**|На строку вниз|
|**Ctrl + ↑**|К предыдущему блоку текста|
|**Ctrl + ↓**|К следующему блоку текста|
|**Ctrl + Y**|На страницу вверх|
|**Ctrl + V**|На страницу вниз|
|**Alt + \**|В начало файла (буфера)|
|**Alt + /**|В конец файла (буфера)|

### **Специальная навигация и управление**

|Сочетание клавиш|Действие|
|---|---|
|**Alt + G**|Перейти на указанную строку|
|**Alt + ]**|Перейти к парной скобке|
|**Alt + ↑**|Прокрутить вид вверх (без движения курсора)|
|**Alt + ↓**|Прокрутить вид вниз (без движения курсора)|
|**Alt + <**|Переключиться на предыдущий открытый буфер|
|**Alt + >**|Переключиться на следующий открытый буфер|

### **Информация и справка**

|Сочетание клавиш|Действие|
|---|---|
|**Ctrl + C**|Показать позицию курсора (строка, столбец)|
|**Alt + D**|Показать статистику (строки, слова, символы)|
|**Ctrl + G**|Отобразить справку|

### **Различные функции**

| Сочетание клавиш | Действие                                                                       |
| ---------------- | ------------------------------------------------------------------------------ |
| **Alt + A**      | Включить/выключить режим выделения текста                                      |
| **Tab**          | Сделать отступ для выделенной области                                          |
| **Shift + Tab**  | Убрать отступ у выделенной области                                             |
| **Alt + V**      | Ввести следующий символ буквально (например, для ввода управляющих комбинаций) |
| **Alt + N**      | Включить/выключить отображение номеров строк                                   |
| **Alt + P**      | Включить/выключить отображение пробельных символов                             |
| **Alt + X**      | Скрыть или показать строки справки внизу экрана                                |
| **Ctrl + L**     | Обновить (перерисовать) экран                                                  |
