## 1. Введение в Nano

**Nano** — простой, интуитивно понятный текстовый редактор, работающий непосредственно в терминале. Является улучшенной версией редактора Pico. Название и функционал содержат множество отсылок, что характерно для экосистемы Linux.

### 1.1. Запуск редактора

```1c
nano                # открыть новый пустой файл
nano filename.txt   # открыть существующий файл
```

### 1.2. Интерфейс Nano

|Элемент интерфейса|Описание|
|---|---|
|Верхняя строка|Версия редактора, имя файла, статус (изменён/не изменён)|
|Основная область|Поле для редактирования текста|
|Информационная строка (нижняя)|Отображается по `Ctrl + C` — показывает позицию курсора (строка, колонка), размер файла|
|Две нижние строки|Справочная информация по горячим клавишам|

**Обозначения в нижних строках:**

- `^` — клавиша **Ctrl**
    
- `M-` — клавиша **Alt** (Meta)

## 3. Работа с файлами

### 3.1. Создание и сохранение файла

1. Запустить `nano`
    
2. Ввести текст
    
3. Нажать `Ctrl + O` для сохранения
    
4. Ввести имя файла (например, `newfile.txt`) и нажать `Enter`
    
5. Нажать `Ctrl + X` для выхода
    

### 3.2. Редактирование существующего файла

```nginx
nano existing_file.txt
```

После внесения изменений сохранить (**`Ctrl + O`**) и выйти (**`Ctrl + X`**).

## 4. Полезные опции Nano

### 4.1. Создание резервной копии — `-B` (заглавная)

```css
nano -B filename.txt
```

При сохранении файла Nano создаёт резервную копию с расширением `~` (тильда) в имени. Например, `filename.txt~` будет содержать версию файла до начала редактирования.

_Проверка:_

```bash
ls -la            # увидим два файла: filename.txt и filename.txt~
```

### 4.2. Открытие файла на определённой позиции

```php-template
nano +<строка>,<колонка> filename.txt
```

_Пример:_

```nginx
nano +3500,20 filename.txt
```

Открывает файл с курсором на строке 3500, колонке 20. Запись без пробелов после `+`.

_При ошибке формата_ Nano выведет сообщение и не откроет файл.


## 5. Работа с буфером обмена

### 5.1. Вырезание и вставка (перемещение строк)

1. Установить курсор на нужную строку
    
2. Нажать `Ctrl + K` — строка вырезана (удалена)
    
3. Переместить курсор в нужное место
    
4. Нажать `Ctrl + U` — строка вставлена
    

### 5.2. Копирование и вставка

1. Установить курсор в начало выделяемого блока
    
2. Нажать `Ctrl + 6` — начать выделение
    
3. Переместить курсор в конец блока (текст выделится)
    
4. Нажать `Alt + 6` — скопировать выделенный блок
    
5. Переместить курсор в нужное место
    
6. Нажать `Ctrl + U` — вставить скопированное
    

## 6. Поиск и замена

### 6.1. Поиск текста

1. Нажать `Ctrl + W`
    
2. Ввести искомый текст (например, `Juliet`)
    
3. Нажать `Enter`
    
4. `Alt + W` — перейти к следующему совпадению
    

### 6.2. Поиск с заменой

1. Нажать `Ctrl + \` (или `Ctrl + Shift + \` / `Ctrl + /` в зависимости от раскладки)
    
2. Ввести текст для поиска (например, `Romeo and Juliet`)
    
3. Нажать `Enter`
    
4. Ввести текст для замены (например, `Boy and Girl`)
    
5. Нажать `Enter`
    

**Варианты действий при замене:**

| Клавиша    | Действие                                          |
| ---------- | ------------------------------------------------- |
| `Y`        | Заменить текущее вхождение и перейти к следующему |
| `N`        | Не заменять, перейти к следующему                 |
| `A`        | Заменить **все** оставшиеся вхождения             |
| `Ctrl + C` | Отменить операцию замены                          |

## 7. Навигация по файлу

### 7.1. Переход к определённой строке

1. Нажать `Ctrl + Shift + _` (или `Ctrl + _` в зависимости от раскладки)
    
2. Ввести номер строки (например, `300`)
    
3. Нажать `Enter`
    

_Проверка:_ `Ctrl + C` показывает текущую позицию курсора (строка, колонка).

### 7.2. Прокрутка и перемещение

- Стрелки — перемещение курсора
    
- `Page Up` / `Page Down` — быстрая прокрутка
    
- `Ctrl + C` — показать позицию курсора
    

## 8. Отмена изменений (Undo)

`Alt + U` — отменяет последнее действие. Можно нажать несколько раз для отмены последовательности изменений. Возвращает файл к более раннему состоянию, вплоть до состояния при открытии.
