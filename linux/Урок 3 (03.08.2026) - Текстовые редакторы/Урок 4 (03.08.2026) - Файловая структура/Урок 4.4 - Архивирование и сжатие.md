## 4. Архивирование и сжатие

В Linux архивирование (объединение файлов в один) и сжатие (уменьшение размера) — это разные операции, которые могут выполняться вместе или раздельно.

### 4.1. Утилита `tar` (стандартный инструмент)

**`tar`** (tape archive) объединяет файлы в один архив. Сжатие подключается отдельными ключами.

#### 4.1.1. Основные ключи `tar`

|Ключ|Описание|
|---|---|
|`-c`|Create — создать архив|
|`-x`|Extract — извлечь файлы из архива|
|`-t`|List — показать содержимое архива|
|`-f`|File — указать имя файла архива|
|`-v`|Verbose — подробный вывод (показывать имена файлов)|
|`-z`|Использовать сжатие gzip|
|`-j`|Использовать сжатие bzip2|

#### 4.1.2. Создание архива (без сжатия)

```nginx
tar -cf archive.tar file1.txt file2.txt
```

Размер архива может быть **больше** исходных файлов из-за служебной информации.

#### 4.1.3. Создание архива со сжатием (gzip)

```nginx
tar -czf archive.tar.gz file1.txt file2.txt
```

Ключ `-z` добавляет сжатие. Файл получает расширение `.tar.gz` (или `.tgz`). Размер значительно меньше исходного.

#### 4.1.4. Просмотр содержимого архива

```nginx
tar -tf archive.tar       # список файлов в архиве
tar -tvf archive.tar      # подробный список (с правами, размерами)
```

#### 4.1.5. Извлечение файлов из архива

```1c
tar -xf archive.tar       # извлечь все файлы
tar -xzf archive.tar.gz   # извлечь из сжатого архива
```

### 4.2. Утилита `zip` / `unzip`

**`zip`** — более привычный для пользователей Windows формат архивации со встроенным сжатием. В Ubuntu может потребоваться установка.

#### 4.2.1. Установка

```bash
sudo apt install zip -y
```

#### 4.2.2. Создание zip-архива

```python
zip archive.zip file1.txt file2.txt
zip archive.zip *.txt                 # все .txt файлы
zip -r archive.zip folder/            # рекурсивно добавить папку
```

#### 4.2.3. Извлечение из zip-архива

```python
unzip archive.zip
unzip archive.zip -d target_folder/   # извлечь в указанную папку
```

### 4.3. Сравнение `tar` и `zip`

|Характеристика|`tar`|`zip`|
|---|---|---|
|Предустановлен|Да (в большинстве дистрибутивов)|Нет (требуется установка)|
|Сжатие|Отдельный ключ (`-z`, `-j`)|Встроенное|
|Расширение по умолчанию|`.tar`, `.tar.gz`|`.zip`|
|Сохраняет права доступа|Да|Частично|
|Популярность в Linux|Стандарт|Распространён, но не стандарт|
## 5. Практические примеры

|Команда|Пояснение|
|---|---|
|`df -h /`|Показывает занятое и свободное место на диске в удобном (читаемом) формате|
|`df -i /`|Отображает количество использованных и свободных inode|
|`du -sh ~`|Показывает общий размер домашней директории|
|`tar -czf texts_backup.tar.gz *.txt`|Архивирует все `.txt` файлы с сжатием в архив `texts_backup.tar.gz`|
|`tar -xzf texts_backup.tar.gz`|Извлекает архив `texts_backup.tar.gz` в текущую директорию|
