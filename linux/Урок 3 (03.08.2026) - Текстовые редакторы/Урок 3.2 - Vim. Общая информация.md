## 1. Введение в Vim

**Vim** (Vi Improved) — текстовый редактор, работающий в терминале. Является редактором **по умолчанию** в большинстве дистрибутивов Linux. В системах команды `vi` и `vim` часто являются псевдонимами друг для друга (вызывают один и тот же редактор).

### 1.1. Ключевые особенности

- Предустановлен практически во всех Linux-системах
    
- Неинтуитивный для новичков, но чрезвычайно мощный
    
- Работает на огромном количестве устройств (от серверов до встраиваемых систем)
    
- Поддерживает плагины (подсветка синтаксиса, интеграция с Git и др.)
    

### 1.2. Запуск редактора

```nginx
vim filename.txt    # открыть файл в Vim
vi filename.txt     # часто то же самое (псевдоним)
```

## 2. Режимы работы Vim

Главная особенность Vim — наличие нескольких режимов работы. Переключение между ними показано на схеме ниже.

![](https://ucarecdn.stepik.net/2578bfaf-f33c-4848-abb7-43f541cf194d/)

### 2.1. Описание режимов

| Режим                         | Как попасть                                       | Назначение                                            |
| ----------------------------- | ------------------------------------------------- | ----------------------------------------------------- |
| **Нормальный (Normal)**       | По умолчанию при открытии, `Esc` из любого режима | Навигация, выполнение команд, переход в другие режимы |
| **Режим вставки (Insert)**    | `i` (insert)                                      | Непосредственный ввод и редактирование текста         |
| **Режим команд (Command)**    | `:` (двоеточие)                                   | Выполнение команд: сохранение, выход, настройки       |
| **Визуальный режим (Visual)** | `v`                                               | Выделение текста для копирования, вырезания, удаления |
## 3. Выход из Vim (самое важное!)

|Команда|Действие|
|---|---|
|`:q`|Выйти (quit) — работает, если нет несохранённых изменений|
|`:q!`|Выйти **без сохранения** изменений (force quit)|
|`:w`|Сохранить (write) — остаться в редакторе|
|`:wq` или `:x`|Сохранить и выйти|

_Примечание:_ все эти команды вводятся в **режиме команд** (после нажатия `:`).

## 4. Редактирование текста

### 4.1. Типовой рабочий процесс

1. Открыть файл: `vim filename.txt` (попадаем в нормальный режим)
    
2. Перейти в режим вставки: нажать `i`
    
3. Ввести или отредактировать текст
    
4. Вернуться в нормальный режим: нажать `Esc`
    
5. Сохранить: `:w`
    
6. Выйти: `:q`
    

Или одной командой: `:wq`

### 4.2. Отмена изменений

| Команда (в нормальном режиме) | Действие                           |
| ----------------------------- | ---------------------------------- |
| `u`                           | Отменить последнее действие (undo) |
| `3u`                          | Отменить последние 3 действия      |
## 5. Команды управления текстом (нормальный режим)

### 5.1. Удаление

|Команда|Действие|
|---|---|
|`dd`|Удалить текущую строку|
|`5dd`|Удалить 5 строк (текущую и 4 следующих)|
|`dw`|Удалить слово от курсора|
|`2dw`|Удалить 2 слова|

### 5.2. Копирование и вставка

|Команда|Действие|
|---|---|
|`p`|Вставить содержимое буфера после курсора (put)|

_Примечание:_ для копирования (yank) используется `y` (например, `yy` — скопировать строку), но в базовом курсе основное внимание уделяется `dd` и `p`.

## 6. Навигация в нормальном режиме

Vim позволяет перемещаться по тексту без использования мыши и стрелок (хотя стрелки тоже работают).

|Команда|Действие|
|---|---|
|`h`|Влево|
|`j`|Вниз|
|`k`|Вверх|
|`l`|Вправо|
|`w`|Вперёд на слово|
|`b`|Назад на слово|
|`0`|В начало строки|
|`$`|В конец строки|

### 6.1. Навигация с числовыми аргументами

| Команда | Действие                           |
| ------- | ---------------------------------- |
| `2w`    | Переместиться на 2 слова вперёд    |
| `10h`   | Переместиться на 10 символов влево |
| `3j`    | Переместиться на 3 строки вниз     |
| `5k`    | Переместиться на 5 строк вверх     |
## 7. Поиск текста

### 7.1. Поиск вперёд

1. В нормальном режиме нажать `/`
    
2. Ввести искомый текст (например, `Romeo`)
    
3. Нажать `Enter`
    

**Навигация по результатам:**

|Команда|Действие|
|---|---|
|`n`|Перейти к следующему совпадению (next)|
|`N`|Перейти к предыдущему совпадению|

### 7.2. Поиск назад

`?` — вместо `/` выполняет поиск в обратном направлении.

## 8. Почему Vim так важен

Несмотря на высокий порог входа, Vim остаётся критически важным инструментом по нескольким причинам:

1. **Предустановлен везде** — в минимальных установках Linux, на серверах, во встраиваемых системах, в Android (через терминал)
    
2. **Не требует графического интерфейса** — работает через SSH на любом соединении
    
3. **Эффективность** — при освоении позволяет выполнять сложные операции с текстом без использования мыши
    
4. **Стандарт** — часто является единственным редактором, доступным в окружениях восстановления системы (rescue mode, single user mode)
