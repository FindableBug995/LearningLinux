## 1. Подготовка и установка ОС

Первоначальный этап работы заключается в развертывании виртуальной среды и установке операционной системы.

| Шаг | Действие | Примечание |
|---|---|---|
| **1** | Создание виртуальной машины | Выполняется в гипервизоре (в данном случае **VMware**) |
| **2** | Установка дистрибутива | Устанавливается произвольный дистрибутив (рекомендуется **Debian 13**) |

## 2. Первичная настройка системы и обновление

Сразу после «чистой» установки система требует базовой конфигурации: настройки прав доступа и обновления пакетов. 

### 2.1. Настройка прав администратора (sudo)

В свежеустановленной системе при попытке выполнить команду с правами суперпользователя вы столкнетесь с ошибкой: `username is not in sudoers file`. Чтобы это исправить, необходимо отредактировать конфигурационный файл.

| Конфигурационный файл | Необходимое действие |
|---|---|
| `/etc/sudoers` | Добавить строку: `Username ALL=(ALL:ALL) ALL` |

*Примечание: Вместо `Username` необходимо вписать логин вашего пользователя.*

### 2.2. Настройка репозиториев — `sources.list`

Для скачивания актуальных версий программ нужно добавить официальные репозитории Debian.

1. Откройте файл списка репозиториев в текстовом редакторе (например, `nano`):
   ```bash
   sudo nano /etc/apt/sources.list
   ```
2. Добавьте в файл официальные репозитории Debian (актуальные списки желательно брать с официальных источников или Github).

### 2.3. Обновление системы — `apt`

После настройки репозиториев необходимо обновить списки пакетов и саму систему до актуального состояния.

```bash
sudo apt update && sudo apt full-upgrade -y
```

## 3. Установка утилит интеграции — `open-vm-tools`

Для корректного взаимодействия гостевой операционной системы с гипервизором VMware (общий буфер обмена, динамическое изменение разрешения экрана и т.д.) необходимо установить инструменты интеграции.

### 3.1. Пошаговая установка и запуск

| Команда | Назначение |
|---|---|
| `sudo apt update` | Обновляет список доступных пакетов (если не было сделано ранее) |
| `sudo apt install open-vm-tools` | Устанавливает пакет утилит VMware |
| `systemctl status vmtoolsd` | Проверяет статус службы (убедитесь, что она `active (running)`) |
| `sudo reboot` | Перезагружает систему для окончательного применения изменений |


## Итог

В этом уроке рассмотрены базовые шаги по развертыванию и первичной конфигурации виртуальной машины:

| Этап | Назначение |
|---|---|
| **Установка ОС** | Подготовка ВМ в VMware и инсталляция Debian 13 |
| **Настройка прав** | Выдача пользователю прав `sudo` через файл `/etc/sudoers` |
| **Обновление** | Конфигурация `/etc/apt/sources.list` и полное обновление системы |
| **Интеграция** | Установка пакета `open-vm-tools` для правильной работы ВМ |

Эти шаги являются обязательным фундаментом (Best Practices) перед началом любой работы и развертыванием сервисов на новом Linux-сервере.
