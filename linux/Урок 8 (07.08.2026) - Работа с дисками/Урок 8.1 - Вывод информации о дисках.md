
В этом уроке рассмотрены основные команды для получения информации о дисках в Linux:

|Команда|Назначение|
|---|---|
|`ls /dev/sd*`|Просмотр файлов устройств|
|`df -h`|Свободное место на смонтированных разделах|
|`df -i`|Использование inodes|
|`du -sh`|Размер директорий|
|`mount`|Список смонтированных файловых систем|
|`sudo fdisk -l /dev/sda`|Таблица разделов (MBR/GPT)|
|`lsblk`|Древовидный список блочных устройств|

**Ключевые понятия:**

- **`/dev`** — директория с файлами устройств
    
- **`sdX`** — обозначение дисков (SATA, USB, SCSI)
    
- **`sdX1`, `sdX2`** — разделы диска
    
- **MBR vs GPT** — форматы таблиц разделов
    
- **GB vs GiB** — метрические (1000) vs двоичные (1024) единицы
    
- **Точка монтирования `/`** — корневой раздел системы
    

- `history` - вывод истории использованных команд

## 1. Устройства в Linux — директория `/dev`

В Linux всё является файлом, включая устройства. Директория `/dev` (devices) содержит специальные файлы, представляющие физические и виртуальные устройства системы.

### 1.1. Обозначения дисков

|Обозначение|Тип устройства|
|---|---|
|`sdX`|SCSI, SATA, USB-диски (современные интерфейсы)|
|`hdX`|IDE-диски (устаревшие, редко встречаются)|
|`nvmeXnY`|NVMe SSD (современные высокоскоростные SSD)|

_Пример:_ `sda` — первый физический диск, `sdb` — второй и т.д.

### 1.2. Разделы диска

К обозначению диска добавляется номер раздела:

- `sda1` — первый раздел на диске `sda`
    
- `sda2` — второй раздел
    
- `sda3` — третий раздел
    

### 1.3. Просмотр дисковых устройств

```bash
ls /dev/sd*          # показать все sd-устройства
ls /dev/nvme*        # показать все NVMe-устройства
```

## 2. Команда `df` — информация о свободном месте

**`df`** (disk free) отображает информацию об использовании дискового пространства всех смонтированных файловых систем.

### 2.1. Базовое использование

```bash
df -h                # human-readable (ГБ, МБ, КБ)
df -hT               # добавить тип файловой системы
df -hT /             # информация только о корневом разделе
```

### 2.2. Фильтрация по типу файловой системы

```bash
df -hT -t ext4       # показать только разделы с ext4
```

### 2.3. Информация об inodes

```bash
df -i                # использование inodes
df -ih               # с human-readable
```

_Важно:_ раздел может быть заполнен не только по месту, но и по количеству inodes.

## 3. Команда `du` — использование дискового пространства

**`du`** (disk usage) показывает, сколько места занимают файлы и директории.

### 3.1. Полезные ключи

|Ключ|Описание|
|---|---|
|`-h`|human-readable|
|`-s`|summary — только итог|
|`-d N`|max depth — глубина вложенности|
|`-c`|total — показать общий итог в конце|

### 3.2. Примеры

```bash
du -sh ~             # размер домашней директории
du -h --max-depth=1  # размер файлов и папок первого уровня
du -ch *.txt         # размер всех .txt файлов с итогом
```

## 4. Команда `mount` — информация о смонтированных файловых системах

Без аргументов `mount` выводит список всех смонтированных файловых систем.

```nginx
mount                # вывести все точки монтирования
```

Вывод содержит много информации, часто используется в сочетании с `grep` для фильтрации:

```perl
mount | grep ext4    # показать только разделы с ext4
```

## 5. Команды `fdisk` и `gdisk` — работа с таблицей разделов

Эти команды предназначены для просмотра и изменения таблицы разделов диска. Они требуют прав root.

### 5.1. Различия между MBR и GPT

|Характеристика|MBR (Master Boot Record)|GPT (GUID Partition Table)|
|---|---|---|
|Макс. размер диска|2 ТБ|9,4 ЗБ (зеттабайт)|
|Макс. количество разделов|4 основных|128 (по умолчанию)|
|Команда|`fdisk`|`gdisk` (более современная)|
|Надёжность|Одна копия|Несколько копий, контрольные суммы|

### 5.2. Просмотр информации о диске с помощью `fdisk`

```bash
sudo fdisk -l /dev/sda
```

Вывод содержит:

- Размер диска (в GiB)
    
- Размер сектора
    
- Тип таблицы разделов (GPT / MBR)
    
- Список разделов с размерами и типами
    

_Примечание:_ обозначение **GiB** (Gibibyte) — это 1024 МБ, в отличие от **GB** (Gigabyte) = 1000 МБ.

### 5.3. Просмотр с помощью `gdisk`

```bash
sudo gdisk -l /dev/sda
```

Аналогичен `fdisk`, но ориентирован на GPT.

## 6. Команда `lsblk` — список блочных устройств

**`lsblk`** (list block devices) — наиболее наглядный способ просмотра информации о дисках и их разделах.

### 6.1. Базовое использование

```undefined
lsblk
```

_Пример вывода:_

> NAME   MAJ:MIN RM  SIZE RO TYPE MOUNTPOINT
> sda      8:0    0   20G  0 disk
> ├─sda1   8:1    0  512M  0 part /boot
> ├─sda2   8:2    0    1G  0 part [SWAP]
> └─sda3   8:3    0 18.5G  0 part /

|Колонка|Описание|
|---|---|
|`NAME`|Имя устройства|
|`SIZE`|Размер|
|`TYPE`|`disk` (физический диск), `part` (раздел)|
|`MOUNTPOINT`|Точка монтирования (если смонтировано)|

### 6.2. Полезные ключи

```graphql
lsblk -f             # показать файловые системы
lsblk -o NAME,SIZE,TYPE,MOUNTPOINT   # выбрать нужные колонки
lsblk -l             # список без древовидной структуры
```

## 7. Определение основного диска

Основной диск (корневая файловая система) определяется по точке монтирования `/`:

```bash
df -h /              # показывает, какой раздел смонтирован в /
lsblk -f | grep /    # найти раздел с точкой монтирования /
```

В выводе `df -h` и `lsblk` корневой раздел будет иметь `MOUNTPOINT` = `/`.

## 8. Сравнение команд для работы с дисками

| Команда (с опциями) | Назначение                                 | Требует root | Особенности                                       |
| ------------------- | ------------------------------------------ | ------------ | ------------------------------------------------- |
| `lsblk`             | Список блочных устройств                   | Нет          | Наглядное древовидное отображение                 |
| `df -h`             | Свободное место на смонтированных разделах | Нет          | Показывает использование дискового пространства   |
| `du -sh`            | Размер директорий                          | Нет          | Для оценки занятого места папками                 |
| `mount`             | Список смонтированных файловых систем      | Нет          | Много информации, удобно фильтровать через `grep` |
| `sudo fdisk -l`     | Таблица разделов диска                     | Да           | Подробная информация о разделах                   |
| `sudo gdisk -l`     | Таблица разделов (GPT)                     | Да           | Современная альтернатива `fdisk`                  |
| `cat /dev/sda`      | Прямой доступ к устройству                 | Да           | Опасно! Не использовать без необходимости         |
## 9. Практические примеры

### 9.1. Просмотр всех дисков и разделов

```nginx
lsblk -f
```

### 9.2. Проверка свободного места на корневом разделе

```bash
df -h /
```

### 9.3. Проверка inodes на корневом разделе

```bash
df -i /
```

### 9.4. Информация о таблице разделов

```bash
sudo fdisk -l /dev/sda
```

### 9.5. Фильтрация смонтированных систем по типу

```bash
df -hT | grep ext4
```
