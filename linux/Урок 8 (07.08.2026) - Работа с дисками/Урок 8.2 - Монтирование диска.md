После перезагрузки монтирование нужно будет выполнить заново (если не прописано в `/etc/fstab`).

## 1. Подготовка нового диска в VirtualBox

Для добавления нового диска необходимо остановить виртуальную машину, затем в настройках перейти в раздел **Носители (Storage)** и нажать кнопку добавления жёсткого диска. Выбрать **Создать**, тип диска **VDI**, размер — 20 ГБ. После этого запустить машину.

## 2. Обнаружение нового диска

После запуска проверяем наличие диска:

```undefined
lsblk
```

Появляется устройство `sdb` размером 20 ГБ. Также его можно увидеть в `/dev`:

```bash
ls /dev/sd*
```

## 3. Создание раздела — `gdisk`

Для работы с диском необходимо создать раздел. Используем `gdisk` (современная альтернатива `fdisk` для GPT):

```bash
sudo gdisk /dev/sdb
```

**Интерактивные команды:**

- `?` — справка
    
- `n` — создать новый раздел
    
- Номер раздела: `1` (Enter)
    
- Первый сектор: Enter (значение по умолчанию)
    
- Последний сектор: Enter (на весь диск)
    
- Тип раздела: `8300` (Linux filesystem) — Enter
    
- `w` — записать изменения и выйти
    
- Подтвердить: `Y`
    

После этого в выводе `lsblk` появляется раздел `sdb1`.

## 4. Создание файловой системы — `mkfs`

На созданном разделе необходимо создать файловую систему:

```bash
sudo mkfs.ext4 /dev/sdb1
```

## 5. Монтирование раздела

### 5.1. Создание точки монтирования

Точка монтирования создаётся в папке `/mnt`:

```bash
sudo mkdir /mnt/newdrive
```

### 5.2. Ручное монтирование

```bash
sudo mount /dev/sdb1 /mnt/newdrive
```

После этого команда `df -h` отобразит новый раздел.

## 6. Настройка прав доступа

По умолчанию новый раздел доступен только root. Чтобы обычные пользователи могли записывать файлы, необходимо изменить права:

```bash
sudo chmod o+w /mnt/newdrive
```

Теперь все пользователи могут писать на новый диск.
